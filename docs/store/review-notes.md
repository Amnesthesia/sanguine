# Notes for the app reviewers (App Store Connect and Play Console)

- Sanguine has no account, no sign-in and no server. There is nothing to log in to, and no demo account is needed.
- All data is stored on the device in an encrypted database. The only network use is the optional backup, which the user turns on in Settings > Privacy and data > Backup. The file is encrypted on the phone before it is uploaded to the user's own iCloud Drive or Google Drive app folder.
- Health data: Settings > Health sync. Nothing is requested during onboarding. Each type is requested when the user switches it on. Data read from or written to Apple Health or Health Connect is used only to show and sync the user's own cycle log. It is never used for advertising or shared.
- Age: the minimum age is 13, asked at onboarding by date of birth. Under 18 the app hides fertility language and sexual-activity logging by default.
- Medical claims: the app is not a contraceptive and not a medical device. The wording is fixed in the listing, onboarding and every estimate screen.
- To see the app with data quickly: complete onboarding with any date of birth that makes the user 18 or older, then use the Period button on Today.
