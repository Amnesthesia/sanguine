# Translating Sanguine

Brief for translators and the clinician who checks the result. Launch languages are en-AU, en-GB and en-US; de, fr, es and pt-BR follow (PLAN.md §6.4). No sentence is machine translated.

## What you receive

`strings-for-translation.csv`, regenerated by `pnpm i18n:extract`:

| Column | Meaning |
| --- | --- |
| `key` | Identifier. Never change it. |
| `en_AU` | Source text. |
| `regulatory` | `yes` for fixed regulatory wording and health-flag text. |
| `context` | The part of the app the string appears in (first part of the key). |
| `translation` | You fill this in. |

## Rules

- Keep every `{placeholder}` exactly as written, in any position the grammar needs. `{lo}` and `{hi}` are numbers; `{point}` is a date.
- Keep the length within about 150 % of the English where you can: buttons and tab labels must fit a phone.
- Tone: calm and plain, the Clue register. Short sentences. No emoji, no exclamation marks, no "your body is telling you". The app addresses women; do not use "ladies", "girls", "feminine" or "womanhood" or their equivalents.
- Words that must have no equivalent in the text: safe, unsafe, protected, contraception, birth control, conceive, "fertile today", "chance of pregnancy", risk, diagnosis, any named condition, abnormal, and advice phrased as "should". Say "typical range" where English says it; never "normal".
- `regulatory = yes` rows are translated, not paraphrased: same claims, same limits, same order. A clinician or regulatory reviewer must approve each one before the language ships (PLAN.md §2.3, §11).
- Estimates are ranges. Never turn a range into a single date, and never turn "estimate" into a promise.

## Returning your work

Send the CSV with the `translation` column filled for every row. The maintainer runs:

```sh
pnpm i18n:import de path/to/returned.csv
```

which rejects the file when a key is missing, empty or unknown, when placeholders differ, or when a string is more than 150 % of the source, and otherwise writes `copy/de.json`. A language appears in Settings > Language only when that file exists and passes `tools/ci/i18n.test.ts`.

## Not covered by the tool

Date, number and temperature formats follow the device locale, not the strings. The store listing, the privacy policy and the consumer-health-data policy are translated separately and need legal review in each region.
