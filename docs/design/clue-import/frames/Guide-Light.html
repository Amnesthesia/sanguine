Bring your Clue history into Sanguine in four steps. Steps 1 to 3 happen in Clue and your email; step 4 is here.

  1. 1

    Step 1: Ask Clue for your data

    In Clue, open More, then Settings, then Download my data.

    MoreSettingsDownload my data

  2. 2

    Step 2: Note the password

    Clue shows a password. Write it down or leave that screen open: you type it in step 4. If Clue says your data was already sent, the same password is still on that screen.

    Clue's password, for step 4•••• •••• ••••
  3. 3

    Step 3: Save the file from Clue's email

    Clue emails you a link. Open it on this phone within 72 hours and save the file to Files.

    Email from ClueOpen the linkSave to Files

    The file name starts withClueDataDownload
  4. 4

    Step 4: Choose the file here

    Sanguine asks for the password, then shows what came across.

    Days you already logged in Sanguine keep your own entry.

Unzipped it on a computer? Choose measurements.json from the folder instead. It needs no password.

The file is read on this phone. Nothing is sent anywhere, and the password is not kept.
