Keep the passphrase and recovery code somewhere private. Without them the backup cannot be opened, by design.

iCloud Drive already holds a copy from another phone, made with a different recovery code or passphrase. Nothing was replaced. To keep both phones in step, enter that phone's recovery code and its passphrase, then turn this on again.
